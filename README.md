نظام شامل ومتطور لإدارة المخازن والمبيعات والمشتريات مع ميزات الذكاء الاصطناعي والتحليلات المتقدمة. تم تطويره باستخدام Python مع واجهة مستخدم حديثة وسهلة الاستخدام.

## الميزات الرئيسية

### 🏷️ إدارة المنتجات
- إضافة وتعديل وحذف المنتجات
- إدارة الفئات والتصنيفات
- تتبع المخزون والحد الأدنى
- البحث والتصفية المتقدمة

### 💰 نقطة البيع
- واجهة بيع سهلة الاستخدام
- إضافة المنتجات بالباركود أو الاسم
- حساب الخصومات والضرائب
- طرق دفع متعددة

### 📦 إدارة المشتريات
- تسجيل فواتير الشراء
- ربط المشتريات بالموردين
- تحديث المخزون تلقائياً
- تتبع حالة الدفع

### 🏢 إدارة الموردين والعملاء
- قاعدة بيانات شاملة للموردين
- إدارة معلومات العملاء
- تتبع التعاملات والمدفوعات

### 📊 التقارير والإحصائيات
- تقارير المبيعات والمشتريات
- تقارير المخزون والأرباح
- إحصائيات مالية شاملة
- رسوم بيانية (قريباً)

## متطلبات التشغيل

- Python 3.7 أو أحدث
- نظام التشغيل: Windows, macOS, Linux
- المكتبات المطلوبة (انظر requirements.txt)

## التثبيت والتشغيل

### 1. تحميل المشروع
```bash
git clone [repository-url]
cd warehouse-management
```

### 2. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 3. تشغيل البرنامج
```bash
python main.py
```

## قاعدة البيانات

يستخدم البرنامج قاعدة بيانات SQLite مع الجداول التالية:

- **users** - المستخدمين
- **categories** - فئات المنتجات
- **products** - المنتجات
- **suppliers** - الموردين
- **customers** - العملاء
- **purchases** - فواتير الشراء
- **purchase_items** - تفاصيل المشتريات
- **sales** - فواتير البيع
- **sale_items** - تفاصيل المبيعات
- **stock_movements** - حركات المخزون
