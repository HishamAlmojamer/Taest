## 🎯 الأدوار والصلاحيات

### 1. مدير عام (Super Admin) 👑
- جميع الصلاحيات بدون استثناء
- إدارة المستخدمين والصلاحيات
- الوصول لجميع التقارير والإعدادات المتقدمة
- إدارة النسخ الاحتياطية والأمان

### 2. مدير (Admin) 🔧
- إدارة المنتجات والمبيعات والمشتريات
- التقارير المالية والمتقدمة
- إدارة العملاء والموردين
- الوصول للتحليلات الذكية

### 3. مدير فرع (Manager) 📈
- العمليات اليومية والمبيعات
- تقارير المبيعات والمخزون
- إدارة العملاء الأساسية
- لوحة التحكم الذكية

### 4. كاشير (Cashier) 💰
- نقطة البيع الذكية
- عرض المنتجات والأسعار
- إدارة العملاء الأساسية
- طباعة الفواتير

### 5. موظف مخزون (Inventory Clerk) 📦
- إدارة المنتجات والمخزون
- المشتريات وأوامر الشراء
- تقارير المخزون والحركة
- تحديث بيانات المنتجات

### 6. مندوب مبيعات (Sales Rep) 🎯
- المبيعات وإدارة العملاء
- تقارير المبيعات الشخصية
- متابعة العملاء المحتملين
- الوصول للتوصيات الذكية

### 7. مستعرض (Viewer) 👁️
- عرض البيانات والتقارير فقط
- بدون صلاحيات تعديل أو حذف
- الوصول للإحصائيات العامة

## 📖 دليل الاستخدام السريع

### 🎛️ لوحة التحكم الذكية
1. انتقل إلى **لوحة التحكم الذكية**
2. راجع **الإحصائيات الفورية** والمؤشرات
3. استخدم **التنبيهات الذكية** للمتابعة
4. اطلع على **التوقعات** لتخطيط المستقبل
5. فعّل **الأتمتة** لتحسين العمليات

### 🛒 نقطة البيع الذكية
1. افتح **نقطة البيع الذكية**
2. استخدم **البحث المتقدم** للمنتجات
3. اطلع على **التوصيات الذكية** للمنتجات المترابطة
4. استخدم **الخصم الذكي** المقترح
5. اختر **طريقة الدفع** واطبع الفاتورة

### 📊 التقارير الذكية
1. انتقل إلى **التقارير الذكية**
2. اختر **نوع التقرير** والفترة الزمنية
3. استخدم **الفلاتر المتقدمة** للتخصيص
4. اطلع على **التحليل الذكي** والرؤى
5. **صدّر** التقرير بالصيغة المطلوبة

### 🤖 الذكاء الاصطناعي
1. استخدم **تحليل الاتجاهات** لفهم السوق
2. اطلع على **توقعات الطلب** للتخطيط
3. استفد من **التوصيات الشخصية** للعملاء
4. راجع **الرؤى التجارية** لتحسين الأداء
